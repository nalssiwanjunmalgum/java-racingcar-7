# java-racingcar-precourse

## 기능 요구 사항
- 주어진 횟수 동안 / n대의 자동차 / 전진 또는 멈출 수 있다 
  - [x] 자동차는 전진할 수 있다
  - [x] 거리 정보가 존재하며, 전진 시 값이 + 1 증가한다.
- 이름을 부여할 수 있다 (전진 자동차 출력한다 -> 자동차 이름을 출력한다)
  - [x] 자동차의 클래스 정보 안에 이름이 존재한다 (직접)

- 전진 조건은 0-9 무작위 수 추출 -> 4이상의 수 이여야 한다.
  - [x] 무작위 수 추출은 제공된 API를 사용 - RandomNumberGenerator 별도의 클래스 구성
    - [x] 수를 새롭게 생성하는 메서드 생성
  - [x] 추출된 수가 4이상이면 자동차는 전진한다 - 거리 정보가 + 1
    - [x] 자동차가 외부로 부터 생성된 수를 받고 조건에 맞게 이동하는 방식

- 외부에서 생성된 수를 자동차에 전달하는 역할을 수행하는게 필요하다 (게임 진행자라는 개념이 있으면 좋겠다)
  - 진행자는 Round 진행을 전반적으로 관리한다.
  - 진행자는 난수 생성기에 새로운 수 생성을 지시한다.
  - 진행자는 생성된 수를 자동차에 전달한다.

## 입출력 요구 사항
- (입력) 입력을 담당하는 클래스는 2가지를 입력받을 수 있어야 한다
  - [] 자동차 이름 입력받기
  - [] 라운드 횟수(총 진행하는 횟수) 입력받기

- (입력) 자동차 이름은 ',' 로 구분하고 이름은 5자 이하만 가능하다 (NameValidator)
    - [x] 자동차 이름은 5자 이하만 가능
    - [x] 입력시 ','로 구분하고 5자 이하인지 검증하는 과정이 요구된다

- (입력) 몇 번의 이동할 것인지 사용자가 입력해야 한다
    - [] 사용자의 입력으로 Round(전체 이동 횟수)가 결정된다
    - [x] 수 사이의 공백은 허용하지 않는다 (NumberValidator)

- (출력) 라운드 별로 (이동할 때 마다 각각의 자동차가 어느 정도 이동했는지 출력할 수 있어야 한다)
- (출력) 게임이 완료되면 누가 우승했는지 알려준다  -> 복수 우승자가 가능하다 
  - [] 여러 명이면 ',' 이용해서 구분해야 한다. 
  - [] 단독이면 단독 우승자 만이 출력되어야 한다
  
- (예외) 잘못된 값을 입력하면 IllegalArgumentException 예외를 던지고 앱이 종료되어야 한다.
  - 잘못된 값이란?
    - [] 이름을 구분할 수 없는 경우 (구분자가 존재하지 않는 경우)
    - [] 이름이 5자 초과된 경우가 존재하는 경우 
    - [] ? 입력하는 횟수가 엄청나게 큰 경우라면?? (Long을 고려해야 하나?)
